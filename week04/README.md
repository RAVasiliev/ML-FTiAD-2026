На лекции продолжили изучать градиентное обучение. Разобрали, как методы используют прошлые градиенты и меняют шаг, а затем перешли от регрессии к линейной классификации.

## Лекция

### 1. SAG и выбор шага

Вспомнили разницу между полным градиентом, mini-batch и SGD. В SAG для каждого объекта хранят последний вычисленный градиент. На первых обновлениях проследили, как меняется их среднее и почему метод использует информацию из прошлых шагов.

Сравнили постоянный шаг, изменение шага по расписанию и подбор по значению ошибки. Для SGD обсудили уменьшение шага по мере обучения: оно помогает ослабить колебания возле минимума.

### 2. Momentum и адаптивные методы

На вытянутой квадратичной функции сравнили траектории GD и Momentum. Инерция накапливает направление движения и меняет поведение метода при колебаниях градиента.

AdaGrad накапливает квадраты градиентов отдельно для каждого веса, поэтому частые и редкие признаки получают разные масштабы обновления. RMSprop постепенно забывает старые квадраты градиентов. Adam объединяет усреднение направления с адаптивным масштабом шага.

### 3. Линейная классификация

На задаче прогноза задержки доставки перешли от числового прогноза к двум классам. Линейный скор задаёт границу между классами. Отступ показывает, по какую сторону границы оказался объект и насколько уверенным получился ответ. Обсудили потерю 0–1 и причину, по которой её неудобно минимизировать градиентным методом.

### 4. Потери и оценка качества

Сравнили экспоненциальную, сигмоидальную, логистическую и hinge-потери как функции отступа. Разобрали, как из потерь отдельных объектов получается функция для обучения модели.

Для проверки классификатора использовали accuracy и рассмотрели её ограничение при дисбалансе классов. Различили абсолютное и относительное улучшение метрики. Отдельно обсудили роли validation при выборе модели и test при окончательной оценке.

## Семинар

На простой квадратичной функции посмотрели, когда большой шаг перескакивает через минимум и когда это мешает сходимости. Затем сравнили GD и Momentum на линиях уровня функции с двумя весами. Отдельно проследили обновления AdaGrad, RMSprop и Adam.

На данных Spambase обучили линейный спам-фильтр пятью методами из одной начальной точки. Сравнили снижение логистической потери на validation, число шагов до заданного уровня потери и ошибки на test. В этом опыте скорость снижения потери различалась сильнее, чем итоговая accuracy.
