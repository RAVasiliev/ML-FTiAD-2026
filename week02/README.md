# Неделя 2. Линейная регрессия

На лекции выводим решение задачи линейной регрессии и разбираемся, как свойства признаков влияют на модель. На семинаре строим прогноз стоимости домов и последовательно улучшаем его, проверяя качество на отложенных данных.

## Лекция

- Метод наименьших квадратов для одного признака и его матричное решение.
- Зависимые признаки и устойчивость решения.
- Обработка признаков, интерпретация и проверка модели.
- Линейная регрессия в Python.

[Презентация лекции](lecture02.pptx)

## Семинар

На данных Ames Housing учимся обучать модель в scikit-learn, сравнивать её с простым базовым прогнозом и оценивать качество по RMSE, MAE и R². Разбираем train/valid/test, пропуски и категориальные признаки, Pipeline, преобразование целевой переменной и подбор параметра Ridge через GridSearchCV.
