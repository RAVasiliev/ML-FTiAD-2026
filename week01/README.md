# Неделя 1. Введение в машинное обучение

[Лекция — PDF](lecture01.pdf)

## Темы лекции

1. **Постановка задачи:** объект, целевая переменная, назначение прогноза.
2. **Данные и признаки:** типы признаков, кодирование категорий, обучающая выборка, доступность признаков в момент прогноза.
3. **Задачи МЛ:** регрессия, классификация, прогнозирование рядов, ранжирование и рекомендации, структурированные ответы, обучение без разметки.
4. **Модель и потери:** семейство моделей, линейная модель, предсказание, функция потерь.
5. **Обучение и качество:** эмпирический риск; MAE, MSE, RMSE, R², MAPE, MSLE и Accuracy; потери Хьюбера и квантильная; влияние критерия на прогноз.
6. **Проверка модели:** train/validation/test, качество на новых объектах, подбор модели, разбиение по времени.
