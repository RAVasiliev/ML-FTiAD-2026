## Оценивание

**Оценка = 0,25 × ДЗ + 0,30 × ПР + 0,15 × КР + 0,30 × ЭКЗ**

- **ДЗ** — средний балл за домашние задания.
- **ПР** — средний балл за проверочные работы (3–4 за курс).
- **КР** — контрольная по пройденным темам в конце ноября — начале декабря.
- **ЭКЗ** — экзамен.
