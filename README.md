# Машинное обучение — ФТиАД, 2026

Курс об основных методах машинного обучения: от постановки задачи и подготовки данных до обучения моделей и оценки качества. Разберём линейные модели, классификацию, деревья и ансамбли, обучение без учителя и рекомендательные системы. На лекциях изучаем идеи и математику методов, на семинарах применяем их в Python.
