## Запуск ноутбука

Семинар посвящён предсказанию стоимости домов: линейная регрессия, разделение train/valid/test, метрики RMSE, MAE и R², обработка числовых и категориальных признаков, Pipeline и подбор параметра Ridge через GridSearchCV.

Данные встроены в ноутбук; отдельный CSV скачивать не нужно. Источники указаны в конце ноутбука.

Установите зависимости в окружение Python:

```bash
python -m pip install jupyter numpy pandas matplotlib "scikit-learn>=1.4"
```

Запустите Jupyter, откройте ноутбук и выполните ячейки по порядку:

```bash
jupyter notebook
```

Лекции представлены в формате PowerPoint (`.pptx`).
