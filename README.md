# Машинное обучение. ФТиАД, 2026

Курс посвящён методам машинного обучения для работы с табличными данными. За основу взяты [лекции Евгения Соколова на ФКН ВШЭ](https://github.com/esokolov/ml-course-hse/tree/master).

Начнём с постановки задачи, линейной регрессии и оценки качества. Затем разберём градиентное обучение, методы классификации, деревья, случайный лес и градиентный бустинг. В конце курса перейдём к кластеризации, снижению размерности и рекомендательным системам.

Для каждого метода будем разбирать математическую постановку, способ обучения и ограничения. На семинарах будем обучать модели на данных, подбирать признаки и параметры, сравнивать результаты и разбирать ошибки.

## Оценивание

**Оценка = 0,25 × ДЗ + 0,30 × ПР + 0,15 × КР + 0,30 × ЭКЗ**

- **ДЗ:** средний балл за домашние задания.
- **ПР:** средний балл за проверочные работы. Планируется 3-4 работы.
- **КР:** контрольная по пройденным темам в конце ноября или начале декабря.
- **ЭКЗ:** балл за экзамен.
